# Pirate Adventure — Текстовая многопользовательская онлайн игра про пиратов

## Описание
Pirate Adventure — это текстовая онлайн игра, в которой вы становитесь капитаном пиратского корабля. Исследуйте моря, сражайтесь с врагами, ищите сокровища и стройте свою пиратскую империю вместе с другими игроками!

## Особенности
- Многопользовательский режим с реальным временем общения
- Исследование островов и морских путей
- Пошаговые морские сражения
- Торговля и развитие корабля
- Создание альянсов и пиратских братств

## Установка и запуск

### Требования
- Python 3.8 и выше
- Flask
- Flask-SocketIO
- Flask-SQLAlchemy
